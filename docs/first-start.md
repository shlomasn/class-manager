# Первый запуск CM в новой школе

Инструкция для комплекта из ветки `school-distribution`. Первая проверка занимает один ученический ПК. После неё можно добавить остальные компьютеры.

## 1. Подготовьте тестовый ПК

Выберите один включённый компьютер с Astra Linux 1.8.4. Уточните у администратора:

- Фактическое имя компьютера и его локальный IPv4. Для первого запуска удобен постоянный адрес или адрес с резервированием DHCP.
- Логин и пароль учётной записи для SSH, а также отпечаток SSH-ключа этого ПК. Для первой команды права sudo не нужны.
- Доступен ли SSH-сервер с компьютера учителя и установлена ли Python 3 на ученическом ПК.

## 2. Запустите CM на компьютере учителя

Полностью распакуйте `CM-Astra-2.7-school-distribution.zip` в папку, в которую у вас есть право записи. При первой проверке с нуля используйте новый профиль ОС. Под уже знакомой учётной записью CM откроет ранее сохранённые списки и настройки.

### Windows

1. Установите Python 3.9 или новее с компонентом Tcl/Tk.
2. Откройте распакованную папку и дважды щёлкните `Start-CM.cmd`.
3. Дождитесь главного окна. При первом запуске нужен Интернет для установки Paramiko.

### Astra Linux

Из распакованной папки один раз установите зависимости. Если у вас нет прав установки, попросите администратора выполнить этот шаг.

```sh
sudo sh Install-CM-Astra.sh
```

Затем из той же папки запустите CM в своём обычном графическом сеансе:

```sh
sh Start-CM.sh
```

## 3. Добавьте кабинет и один компьютер

1. Откройте **Управление и настройки → Кабинеты → Добавить кабинет…** и введите название, например «Учебный 1».
2. Откройте **Управление и настройки → Компьютеры → Добавить ПК…**. Выберите кабинет, укажите фактическое имя компьютера и логин SSH.
3. Выберите **Постоянный IP**, если адрес закреплён за ПК, или **По имени (DHCP / DNS)**, если ОС учителя разрешает это имя. Можно ввести полное имя, например `pc-01.school.example`. Для коротких имён домен задаётся в **Управление и настройки → Домен для имён ПК…**. Если домен не нужен, оставьте поле пустым.
4. Для отдельной учётной записи используйте **Для этого ПК**. Если оставить пароль пустым при добавлении, CM попросит его при первой операции с входом по SSH. Если указать пароль в карточке, CM сохранит его в Windows Credential Manager или Secret Service на Astra. Режим **Общий user** использует один сохранённый пароль для ПК с этим режимом и логином `user`.

## 4. Проверьте связь и выполните первую команду

1. Отметьте только тестовый ПК в столбце **Выбор** и нажмите **Проверить связь**. Статус **SSH доступен** показывает, что сервер ответил. Логин, пароль и доверие к новому ключу проверяются на следующем шаге.
2. Нажмите **Команда…**, замените предложенный текст на `hostname`, оставьте рабочую папку `~` и проверьте, что **Выполнить от root через sudo** выключено. Нажмите **Продолжить…**. Команда выводит имя компьютера.
3. Если открылось окно **Первое подключение: SSH-ключи**, сверьте имя, адрес и отпечаток с данными администратора. Подтвердите доверие только при совпадении. При расхождении нажмите **Отмена** и уточните данные.
4. Сверьте список в подтверждении запуска. Введите пароль SSH, если CM его запросит. Когда команда завершится, откройте **Результаты** и проверьте, что возвращено имя тестового ПК.

## 5. Добавьте остальные ПК

- **Поиск.** В меню **Компьютеры → Найти ПК в моей сети…** выберите школьное подключение, проверьте предложенный диапазон, запустите поиск и сверьте ключи обнаруженных ПК. В большой сети (например, при маске 255.255.0.0) для другого кабинета введите IP одного из его ПК в поле **IP из нужного кабинета**. После проверки с логином и паролем отметьте нужные записи и выберите кабинет.
- **CSV.** Скопируйте [шаблон CSV](../computers-example.csv) и заполните колонки `кабинет;компьютер;логин`. Сохраните CSV с разделителем «точка с запятой» в UTF-8. В меню **Компьютеры → Импорт списка .csv / .lst / .json…** проверьте предварительный список и подтвердите импорт. CSV добавляет или обновляет записи по имени. Пароли задаются отдельно через CM. Для новых записей с неразрешимыми именами задайте постоянные адреса в карточках.

## 6. Сохраните данные перед переустановкой

При обновлении программы под той же учётной записью CM автоматически открывает данные из профиля ОС. Перед переустановкой системы или переходом на другой компьютер откройте **Управление и настройки → Данные школы → Сохранить копию…** и сохраните JSON на отдельный носитель или в папку резервных копий.

В новом профиле выберите **Данные школы → Восстановить из копии…**, проверьте число кабинетов, ПК и домен, затем подтвердите замену. В копии есть кабинеты, карточки ПК и домен. Пароли хранятся в системе, а доверенные SSH-ключи привязаны к профилю CM. В новом профиле их нужно ввести и подтвердить заново.

## Если что-то пошло не так

| Что видите | Что проверить |
| --- | --- |
| Окно запуска закрылось или показало ошибку | На Windows проверьте Python с Tcl/Tk и Интернет для первого запуска. На Astra проверьте, завершилась ли установка зависимостей, и запускайте CM из обычного графического сеанса. |
| Не удалось найти адрес по имени | Проверьте имя и домен. Если ОС учителя не разрешает имя, укажите постоянный IPv4 известного ПК. |
| SSH недоступен или список поиска пуст | Проверьте, что ПК включён, SSH работает, порт 22 доступен и выбрана школьная сеть. |
| Ошибка входа | Проверьте логин в карточке, режим учётных данных и пароль. Исправьте данные и повторите проверку на одном ПК. |
| SSH-ключ изменился | Уточните у администратора, менялся ли компьютер или переустанавливалась ли ОС, и сверьте новый отпечаток. |
| Secret Service не сохранил пароль | Откройте или разблокируйте связку ключей Astra в своём графическом сеансе. Для проверки можно вводить пароль по запросу. |

Дополнительные сведения о сети, хранилищах паролей и отчётах есть в [справке CM](../README-RU.txt).
