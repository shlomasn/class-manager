# Первый запуск CM в новой школе

Черновик инструкции для проверки на Windows и Astra Linux. Шаги ниже рассчитаны на комплект из ветки school-distribution.

## Подготовьте один ученический компьютер

Для первой проверки достаточно одного включённого ПК с Astra Linux 1.8.4. Узнайте его точное имя, локальный IPv4-адрес и логин для SSH. Попросите администратора убедиться, что на ПК работает SSH-сервер и установлена Python 3. Компьютер учителя должен иметь доступ к этому ПК по сети.

## Запустите CM на компьютере учителя

Распакуйте `CM-Astra-2.7-school-distribution.zip` в отдельную папку. Для проверки с нуля используйте новый профиль операционной системы. CM загружает сохранённые данные текущего профиля.

- **Windows.** Установите Python 3.9 или новее с Tcl/Tk и запустите `Start-CM.cmd` из распакованной папки. При первом запуске нужен Интернет для установки Paramiko.
- **Astra Linux.** Откройте терминал в распакованной папке. Один раз выполните `sudo sh Install-CM-Astra.sh`. Затем запустите `sh Start-CM.sh` в графическом сеансе обычного пользователя.

## Добавьте кабинет и проверьте связь

1. В меню **Управление и настройки → Кабинеты → Добавить кабинет…** укажите название кабинета.
2. В разделе **Компьютеры → Добавить ПК…** добавьте тестовый ПК в этот кабинет. Укажите его имя и логин SSH. Для адреса можно выбрать постоянный IPv4, если имя ПК не разрешается на компьютере учителя. Индивидуальный пароль можно сохранить в карточке. CM использует системное хранилище паролей.
3. Отметьте тестовый ПК и нажмите **Проверить связь**. Статус **SSH доступен** означает, что CM смог обратиться к SSH-серверу. Проверку логина и пароля выполняет операция, для которой нужен вход на ПК.
4. Если SSH недоступен, проверьте адрес, питание ПК и доступность SSH из сети учителя. При первом запросе доверия к SSH-ключу сверьте отпечаток с администратором. Если известный ключ изменился, выясните причину на самом ПК.

После проверки одного компьютера список можно пополнить через **Компьютеры → Найти ПК в моей сети…** или через **Импорт списка .csv / .lst / .json…**. Для CSV возьмите [шаблон](../computers-example.csv) с колонками `кабинет;компьютер;логин`. Пароли в CSV не указываются.

Подробности установки, сети и системного хранилища есть в [справке CM](../README-RU.txt).
